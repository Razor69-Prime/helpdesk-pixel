PXL-REV-0005 — Inventory Supabase Integration

File yang berubah:
- public/inventory.html
- server.js
- db.js
- supabase-inventory.sql

Langkah implementasi:
1. Jalankan supabase-inventory.sql di Supabase Dashboard > SQL Editor.
2. Salin public/inventory.html, server.js, dan db.js ke project lokal.
3. Jalankan npm install bila diperlukan.
4. Jalankan npm start untuk tes lokal.
5. Commit dan push ke GitHub.

Fitur aktif:
- Tambah barang dengan stok awal.
- Restock barang.
- Statistik stok.
- Log transaksi.
- Material Request teknisi dan pengurangan stok.
- Stock opname dan adjustment stok.

Catatan:

- Tidak ada data dummy.
- Scan kamera fisik belum diaktifkan; pencarian manual sudah aktif.
