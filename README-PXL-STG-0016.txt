PXL-STG-0016 — Daily Report Header
STAGING ONLY
- Header: DAILY REPORT PROJECT PIXEL <tahun>.
- Date/Days memakai tanggal achievement terakhir yang tersimpan.
- Project Name dari Project Tracker.
- Project ID membaca nomor SO/WO yang tersedia pada data project; jika keduanya ada ditampilkan SO / WO.
- PIC memakai created_by pada achievement terakhir (fallback user login).
- Team sementara '-' karena Project Tracker belum memiliki relasi team khusus.
- WhatsApp dan PDF memakai header yang sama.
- Tidak memerlukan SQL.
