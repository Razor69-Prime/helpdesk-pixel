PXL-STG-0008A27 — Invoice PDF, Detail Reference, dan Perapian Piutang

Scope: staging saja. Main dan production tidak disentuh.

Perubahan:
1. Invoice berstatus Terbit, Sebagian, atau Lunas memiliki tombol Download PDF
   di daftar Invoice dan halaman detail Invoice.
2. PDF hanya dapat dibuat setelah Invoice diterbitkan; Draft tidak memiliki
   dokumen PDF resmi.
3. Detail Invoice kini menampilkan Customer, Customer PIC, Sales PIC, nomor
   SO, seluruh nomor WO terkait, tanggal invoice, jatuh tempo, jenis/termin,
   total, terbayar, dan sisa piutang.
4. Daftar Piutang memiliki kolom Referensi SO / WO agar tracking lebih mudah.
5. Ukuran font dan tombol pada daftar/detail Invoice dibuat lebih ringkas.

Tidak ada SQL baru.
