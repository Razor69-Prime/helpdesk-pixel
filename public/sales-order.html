Sales Order

Modul khusus pembuatan, daftar, status, dan histori Sales Order. Project Tracker tetap dikelola pada modul Project Tracker.
Buat Sales Order
Nomor SO dibuat otomatis dan tidak dihapus. Gunakan status void/cancelled untuk menjaga histori.
Sales Order berstatus Disetujui dapat dibuatkan Work Order operasional. Satu Sales Order hanya dapat memiliki satu WO; setelah dibuat tombol berubah menjadi Buka Work Order.
Daftar dan Histori Sales Order
Semua SO tetap tercatat termasuk yang dibatalkan atau void.
