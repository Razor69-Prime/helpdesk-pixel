✏️ Edit Akun
Mengubah username tidak mempengaruhi data historis (tiket, kunjungan, dll) — semua tetap terhubung ke akun ini.
Akun non-aktif tidak bisa login dan tidak muncul di pilihan dropdown teknisi/sales baru.
Tidak mengubah akses menu — hanya membuat akun ini juga muncul di dropdown Sales PIC dan/atau Teknisi (Set Target, KPI, Assign Teknisi, dll).
Kalau dicentang, akun ini akan melihat opsi "Tidak ada WO terkait" di form Upload Invoice — bisa input omzet/nominal tanpa perlu pilih tiket.
Jika dikosongkan semua → mengikuti default role. Jika ada yang dicentang → override role.
